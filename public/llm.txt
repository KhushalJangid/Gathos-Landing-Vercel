# Gathos

> Gathos is an API platform built for AI agents. Pro includes image generation with strong long-text rendering and TTS with zero-shot voice cloning across 600+ languages for $18/month. Creator adds text-to-video with generated audio, optional Styles, async ETA-aware polling, and video API keys for $45/month. Purpose-built for Claude Code, Cursor, Windsurf, Gemini CLI, OpenClaw, Aider, Copilot, ChatGPT Custom GPTs, and any REST-capable agent.

## Quick facts

- Pricing: **Pro is $18/month** for image generation + TTS. **Creator is $45/month** and includes Pro plus Creator video. No credits, no per-image fees.
- Trial: 7 days free, up to 25 calls/day across image + TTS during trial, 140 lifetime trial generations, no credit card required.
- Image Generation API: async PNG jobs. Prompt must be 1-2,000 characters. Width and height must be 512-2048 and divisible by 16. Guidance scale is 1.0-7.0. Steps are 4-30.
- TTS API: async speech jobs with zero-shot voice cloning from a 5-30 second reference sample. Built-in preset voices include Josh, Koko, Pixxy, Prof, Rochie, and Spraky. 600+ languages.
- Creator Video API: async text-to-video with AI-generated audio. Public launch is text-to-video only (`mode: t2av` internally). Optional user-facing Styles are resolved server-side; clients do not need internal preset filenames.
- Video frame counts: request any numeric `num_frames`; Gathos snaps it to the nearest valid LTX frame count between 9 and 513. Examples: 120 -> 121, 240 -> 241.
- ETA fields: queued and processing jobs may return `eta_seconds`, `estimated_completion_time`, `queue_position`, `queue_depth`, and `estimate_source`. Treat estimates as approximate and hide them after completed/failed.
- Authentication: Bearer tokens. Key types are `img_live_*` for image generation, `tts_live_*` for TTS, and `vid_live_*` for Creator video. Legacy `img_live_*` keys can also call video for Creator accounts.
- Endpoints: `POST /api/v1/image-generation`, `GET /api/v1/image-generation/jobs/{id}`, `POST /api/v1/tts`, `GET /api/v1/tts/jobs/{id}`, `GET /api/v1/tts/voices`, `POST /api/v1/video-generation`, `GET /api/v1/video-generation/jobs/{id}`, `GET /api/v1/video-generation/styles`.
- Public API architecture: clients call gathos.com proxy endpoints only. Do not call GPU workers directly. The proxy handles auth, tier headers, queueing, ETA estimates, and backend routing.
- Rate/concurrency: `/api/v1` has a shared 60 requests/minute per-IP cap including polling. Image submissions are capped per user at admin 5, Pro/Creator 2, Trial 1 in-flight with a 5s submit cooldown. Video is 1 in-flight job per user with a 10s submit cooldown and 5-10s polling cadence.
- Agent skills are available from the dashboard: Idea-to-Presentation (`.pptx` + narrated `.mp4`), YouTube Video Factory (1920x1080 `.mp4` + thumbnail), and Script-to-Reel (1080x1920 vertical `.mp4`).

## What makes Gathos different

- **Readable long text inside images.** Gathos is built for slides, thumbnails, posters, infographics, UI mockups, and generated assets where labels and long copy need to remain legible.
- **Zero-shot voice cloning bundled with Pro.** Upload or reference a voice sample and generate multilingual TTS without buying a separate voice product.
- **Creator video on the same account.** Creator adds text-to-video with generated audio and optional Styles while keeping the Pro image and TTS APIs included.
- **Agent-first API surface.** Designed for shell-capable agents that generate creative assets as part of larger pipelines: deck -> script -> visuals -> voiceover -> video.
- **Predictable pricing.** Pro replaces per-image and per-character metering for image + TTS. Creator adds video for one predictable monthly plan.

## Common questions (canonical answers)

- **What is Gathos?** Gathos is an API platform for AI agents. Pro gives image generation and TTS. Creator adds text-to-video with generated audio.
- **How much does Gathos cost?** Pro is $18/month. Creator is $45/month. A 7-day free trial is available before upgrading.
- **Which agents does Gathos work with?** Any shell-capable or REST-capable AI agent, including Claude Code, Cursor, Windsurf, Gemini CLI, OpenClaw, Aider, GitHub Copilot, ChatGPT Custom GPTs, Continue, LangChain, and CrewAI.
- **What makes image generation different?** Gathos is optimized for reliable text-in-image workflows where readable headlines, labels, UI copy, or slide text matter.
- **Does voice cloning cost extra?** No. Voice cloning is included in Pro and Creator TTS access.
- **How many languages does TTS support?** 600+ languages and accents for both text-to-speech and zero-shot voice cloning.
- **Does Creator video support image-to-video or audio-input video?** Not in the public launch. Creator currently exposes text-to-video with generated audio only. Do not build UI for image_url or audio_url modes until Gathos explicitly releases them.
- **How should clients handle video frame counts?** Send the requested numeric `num_frames`; Gathos snaps it to the nearest valid LTX count automatically.
- **How do I get the agent skills?** Sign in at https://gathos.com/login and open the Skills tab of your dashboard. Skills use your Gathos API keys and call the hosted Gathos proxy APIs.
- **Is there a refund policy?** Yes, see https://gathos.com/legal?tab=refund.
